# mouse_pointer_focuser

Значок в трее Linux (X11): по горячей клавише курсор мыши прыгает в центр выбранного монитора,
а окно под ним становится активным.

## Запуск

```
/usr/bin/python3 app.py
```

Зависимости: `pystray`, `python-xlib`, `Pillow`, PyGObject (GTK 3); `xdg-open` и `notify-send`.
Запускается только один экземпляр.

## Меню (левый или правый клик)

- **Курсор на монитор** — то же, что горячая клавиша.
- **Мониторы** — список подключённых мониторов (обновляется при подключении и отключении);
  клик переносит курсор на выбранный, галочка показывает текущий из настроек.
- **Настройки** — открывает `config.toml` (создаётся из `config.template.toml`).
- **Запускать при входе** — запись в `~/.config/autostart`.
- **Перезапустить** — нужен, чтобы применить новую горячую клавишу.

## Настройки

Все параметры описаны в `config.template.toml`:

- `hotkey` — сочетание клавиш, по умолчанию `ctrl+alt+shift+m`;
- `monitor` — номер монитора, считая слева направо с 1;
- `monitor_name` — имя выхода (`DP-1`, `HDMI-0` …); если задано, важнее номера;
- `focus_window` — делать ли активным окно под курсором.
